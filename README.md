# Senior .NET — Interview Lab

Браузерный тренажёр технических собеседований: 36 практических вопросов по шести направлениям.

## Что внутри

- CLR и GC, async/await и многопоточность, C# и память, EF Core, PostgreSQL, архитектура.
- Один вопрос на экране, поле ответа и раскрываемый разбор.
- Эталон, ключевые тезисы, типичные ошибки, уточняющий вопрос и ссылка на документацию.
- Самооценка «Не разобрался / Частично / Уверенно».
- Фильтры тем и результатов, режим повторения, случайный вопрос, карта подготовки.
- Общий прогресс и прогресс по каждой теме без двойного подсчёта повторных попыток.
- Автосохранение черновиков и оценок в localStorage этого браузера.
- Адаптивная вёрстка, клавиатурная навигация и Ctrl/Cmd + Enter для разбора.

Оценка самостоятельная: приложение не отправляет ответы на проверку ИИ. Сервер, API-ключи и база данных не нужны. Данные не синхронизируются между устройствами; очистка данных сайта удалит локальный прогресс. Публикация через Pages не добавляет авторизацию посетителей.

## Запуск через GitHub Pages

1. Открыть **Settings → Pages** в репозитории.
2. В **Build and deployment → Source** выбрать **Deploy from a branch**.
3. Указать **main** и папку **/(root)**, затем **Save**.

`index.html` уже лежит в корне, все пути относительные. Сборка и установка npm-пакетов не требуются. `.nojekyll` отключает обработку Jekyll.

## Локальный запуск

ES-модули нужно открывать через HTTP-сервер, а не двойным кликом по HTML:

```sh
python -m http.server 8000
```

Открыть `http://localhost:8000/`.

## Проверка

Нужен современный Node.js с встроенным test runner, без установки зависимостей:

```sh
npm test
```

Проверяются полнота банка, фильтры, подсчёт прогресса, повторная оценка, восстановление состояния, повреждённые сохранения, навигация и завершение подготовки.
